# 线稿控制图升级复测：细线骨架 → 有体积人偶（ST-04 / 05 / 09）

> 日期 2026-11-05 · 批准预算 0.36 元 · **实际花费 0.36 元**（3 张 × 0.12，按目录价；结算 T+1 以 billing 为准）
> 结论：**B 部分有效**。跨躯干（ST-05）与侧视上举（ST-09）由「失败」翻为「通过」；
> 手部需要「藏进身体/衣物」的 ST-04 仍失败，且比上一轮更差。

---

## 1. 改了什么（唯一变量 = 控制图是否携带体量）

`gen_mannequin.py` 用与细线骨架**同一套关节坐标**（导入 `gen_skeleton.POSES`）画出人偶：

| 细线骨架（上轮） | 有体积人偶（本轮） |
| --- | --- |
| 等粗线 + 小圆点，宽 15px | 带锥度柱体（近端粗/远端细），肩宽 188px、大腿 64px |
| 躯干 = 一条脊柱线 | 胸廓 / 收窄腰 / 骨盆三个体块，接缝收窄成短弧（读作结构线） |
| 关节点半径 11px | 实心球：肩 22 / 肘 16.5 / 髋 20 / 膝 17.5，手为沿前臂的椭球 |
| 部件互相穿过、无描边 | 每个部件独立描边（外扩 4.6px 画 INK 再压本体），叠压靠各自轮廓分开 |
| 白底深灰线 | 白底深灰实体（INK `#2E2925` / BODY `#6E6860` / HI 高光），侧视远侧腿用 DARK 分层 |

提示词同步把参考图改称「人体人偶（艺术家木人台模型）」，并显式要求
「深灰实体块一律改为空心轮廓线」——否则模型会把实心块直接当衣服保留。

**另做了 3 处与封面的一致性校正**（原关节数据在手臂上本来就偏离封面照片，
若不校正，测的就不是"模型能不能画对"，而是"数据对不对"）：

| ID | 原数据 | 与封面不符之处 | 校正 |
| --- | --- | --- | --- |
| ST-04 | 两腕 518 / 570（仅差 52px ≈ 胯宽 1/3） | 等于"双手在裆前合拢"，这就是上轮被画成"手在身前握在一起"的**直接原因** | 手位外移到胯前袋口 496 / 592，肘收起 430 / 652 |
| ST-05 | 左右腕 516 / 528 各跨到对侧 | 两条前臂交叉成 **X**，读作"抱胸打了个叉" | 改为近乎水平、上下叠放 562 / 632（间距 70px） |
| ST-09 | 一手搭眉骨 + 一臂上举 | 封面是**双臂一并过头相扣、后仰、踮脚** | 双腕改到 520,178 / 568,162 |

## 2. 三张结果（证据：`_vol-compare.png`，5 列对照）

判据：① 手臂动作是否保住（肘/腕朝向、与躯干相对关系）② 对照封面能否认出是同一姿势。

| ID | 姿势 | 上轮（细线骨架） | 本轮（人偶） | 判定 |
| --- | --- | --- | --- | --- |
| ST-04 | 双手插袋 | 手被拉到身前合拢 | 手臂走向与肘部弯曲**保住了**（上臂贴体、前臂内收），但**两手被模型收到身前扣在一起**，读作"双手交握" | **× 未保住** |
| ST-05 | 松弛环抱 | 交叉手臂被整体抹平 → 自然下垂 | 两条前臂**水平叠抱**，一手插进对侧臂弯，与封面同姿势 | **√ 保住** |
| ST-09 | 踮脚伸展 | 双臂被放下 | 侧视、**双臂过头相扣**、后仰、踮脚，与封面同姿势 | **√ 保住** |

**ST-04 的失效机制（本轮新发现，可直接指导下一版）**：控制图里两手只是"分居胯侧、相距两掌"，
一旦手部与骨盆都是同一实体色，**手与胯的边界对比度反而低于细线骨架**（细线时手是独立圆点），
模型于是把"手+胯"合并读成一个整体，输出成"双手交握"。也就是说，
**手部需要"藏进身体"（插袋/抱膝/藏背后）这类要求遮挡关系的姿势，体块控制图是反向作用的**。

## 3. 结论 B：哪类能做、哪类回落矢量

**可以走 AI 线稿（人偶控制图）**
- 手臂**离开躯干**的跨体动作：交叉叠抱、抱臂、手插对侧臂弯（ST-05 已验证）
- **侧视/近侧面 + 肢体高举过头**（ST-09 已验证，上轮此类 0/2）
- 手臂在头/脸附近（上轮 2/2，本轮沿用同一坐标，风险低）

**必须回落矢量骨架（`skeleton/ST-xx.svg`，930B，姿态 100% 正确，零成本）**
- 手部与身体发生**遮挡/藏入**关系：插袋、抱膝、手藏背后、手扶腰侧（ST-04 本轮反证）
- 结论上轮同类：ST-03「靠墙站」这类**需要环境支撑物**的姿势（骨架也没有墙，本轮未测）

**未测（预算所限）**
- ST-07「侧张双臂」：上轮失败 1 次、文字补强 1 次仍失败。按"手臂远离躯干"类推**预期可做**，
  但本轮无证据；若要铺全量，建议先用 0.12 元补测一张。
- 文字补强分支（`run_vol.py --variant fix`）本轮未跑：预算 0.36 已全部用于 base 版，
  且上轮已验证"加字救不回"，本轮不做重复投入。
