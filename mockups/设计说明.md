## 3. 动效规范

### 3.1 令牌（统一出处，组件只引用不写死）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--dur-fast` | 150ms | 按压 / hover / 颜色微交互 |
| `--dur-base` | 240ms | chips、按钮、心标弹跳 |
| `--dur-slow` | 420ms | 卡片进场、抽屉、轮播位移 |
| `--dur-page` | 320ms | 页面转场 |
| `--ease-out` | `cubic-bezier(.22,1,.36,1)` | 所有进场（绝不 linear） |
| `--ease-inout` | `cubic-bezier(.60,0,.30,1)` | 抽屉 / 轮播位移 |
| `--ease-spring` | `cubic-bezier(.34,1.56,.64,1)` | 心标收藏等强调反馈（轻微过冲） |
| `--stagger` | 45ms | 列表逐个延迟（封顶 420ms） |

### 3.2 什么时候动什么

| 场景 | 行为 |
| --- | --- |
| 页面转场 | 点击链接 → 当前页 170ms 淡出下移 → 跳转；新页内容按 `--stagger` 依次淡入上移（原型为 JS 离场 + IntersectionObserver 进场；正式 Vue SPA 换成 `<router-view>` Transition，令牌不变） |
| 卡片流进场 | 骨架屏（shimmer）→ 内容替换 → 卡片 420ms ease-out 逐个上浮（45ms 步进）；封面 3:4 `aspect-ratio` 占位，CLS≈0 |
| 详情图集 | 轮播 420ms ease-inout 位移；圆点宽度过渡；箭头 hover 浮现；点击进入 Lightbox（scale 0.96→1） |
| 筛选抽屉 | 底部抽屉 420ms ease-inout 上滑 + 遮罩淡入；桌面侧栏常驻无动画；拖拽把手可下滑关闭 |
| 微交互 | 按钮 :active scale(.96)；心标收藏 spring 弹跳 ×1.25；对比浮条 spring 进出场；Toast 底部滑入 240ms |

### 3.3 降级

`@media (prefers-reduced-motion: reduce)` 全局关闭过渡/动画/平滑滚动，内容直接呈现；JS 侧 `PG.REDUCED` 同步跳过 stagger 与轮播动画。

## 5. 组件与页面评估要点

- **index.html**：四页入口 + 评估指引；缩略图即真实 cover 生成器输出。
- **home.html**：今日推荐每日 3 个轮换（步长 8 保证跨分类，**正式策略，决议 #14**）+「换一批」420ms 骨架过渡；十类入口 2/5/10 列渐变（单字衬线 monogram + 品类色 tint）；主题合集改为**光线·场景主题**（「窗光与生活感」「黄金时刻」等，无多人内容，决议 #13）16:9 横滑→3 列；卡片流为**瀑布流布局 + 滚动无限加载**（决议 #19）。
- **library.html**：分类 chips 横滑 + 右侧「筛选」按钮（带命中数角标）；筛选维度内 OR、维度间 AND，实时「命中 n 条」；已选 chips 可单个删除/一键清空；空结果给「放宽条件」；对比浮条「已选 n/3」spring 进出场；支持 `?cat=ID` 直达；列表**触底自动加载**（决议 #19）。
- **detail.html**：图集三帧（示例→线稿标注→错误示范）支持拖拽/箭头/圆点/键盘←→/点击放大，**正式版另实现双指捏合缩放（决议 #17）**；机位卡四行 + 构图示意小图；分步要点纵向 stepper；避坑区红色 ✕ + 错误示范缩略图；构图小贴士（灰绿卡，按品类取材，决策 #8）；操作：移动底部固定 / 桌面右栏 sticky（收藏、加入清单、加入对比、分享）；底部相关推荐（**算法 v1 定案，决议 #24，见 §8**）；顶部 prev/next 同类切换，**正式版支持左右滑切换同类姿势（决议 #18）**。
- **悬浮入口（决议 #20）**：收藏 / 清单 / 搜索 / 对比 / 我的等范围外功能，收纳为一颗**可收缩悬浮球（FAB）**——单击展开为环形菜单（spring 特效），再次点击或 ESC 收起；具体页面本体仍按排期延后。

## 6. 可访问性（WCAG AA）

- 正文对比 ≥4.5:1（`--c-ink-2` 6.5:1；`--c-ink-3` 仅用于 ≥ 大字号/装饰，正文不用）；彩色文字用 `--c-accent-deep`
- 触点 ≥44px（移动端 chips/图标按钮/底部操作）；`:focus-visible` 统一 2px 描边
- 语义 + ARIA：skip link、`aria-current="page"`、抽屉 `role="dialog" aria-modal="true"`、筛选按钮 `aria-expanded`、ESC/遮罩关闭并还焦点、心标 `aria-pressed`、图集箭头 `aria-label`、装饰 SVG `aria-hidden`
- 键盘：图集 ←→ 切换、ESC 关抽屉/Lightbox、全部链接可 Tab
- `prefers-reduced-motion` 全套降级（见 §3.3）
- 新增交互的可访问性（对应决议 #19/#20/#17/#18）：瀑布流图片逐张 `alt`＋原生懒加载，不阻塞键盘流；无限滚动提供「加载更多」兜底按钮（键盘可达）与 `aria-live` 加载状态播报；悬浮球 `aria-expanded`＋展开后焦点移入首个菜单项、ESC 收起并还焦点；双指缩放与左右滑动手势均保留按钮等价操作（图集箭头 / prev-next 胶囊）

### 8.1 相关推荐算法 v1（定案）

> 需求方授权「寻找最合适的算法，你定」。选型依据：100 条精选目录、无行为数据冷启动、需要可解释与可复现——内容基线过滤优于协同过滤。

- **打分**（候选 = 全库除自身）：同分类 **+10**；共享标签 **+3/个**（最多计 3 个，封顶 +9）；同光线类型 **+2**；同场景标签 **+2**；难度差 ≤1 **+1**；上线后追加收藏行为分 **+0~5**（冷启动为 0，不改变初版结果）。
- **多样性重排**：最终 6 个中同分类最多 3 个——按得分降序贪心选取，超限跳过补位。
- **门槛与兜底**：总分 <6 的位次按同分类内 seed 顺序补足；平局一律按 seed 稳定排序（结果可复现、缓存友好）。
- **工程形态**：100×100 相似矩阵构建期预计算（约 1 万对，毫秒级），运行时查表 O(1)；后续接入行为分仅改矩阵权重，不动接口。
