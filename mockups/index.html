如何评估

  1. 建议用 Chrome / Edge 打开各页面；每页左下角「390 预览」可在桌面浏览器中直接查看移动端布局（iframe 内媒体查询按 390px 生效）。
  2. 直接缩放窗口验证断点：<768px 底部 Tabbar ＋ 2 列网格；768–1199px 顶部导航；≥1200px 桌面双栏/多列与筛选侧栏常驻（重点看 390 与 1440 两档）。
  3. 动效清单：页面转场（离场/进场）、卡片流骨架屏与 stagger 进入、详情图集轮播、筛选抽屉与侧栏、心标/按钮/卡片微交互——统一走 tokens.css 的时长与缓动令牌。
  4. 系统开启「减弱动态效果」后再访问，可验证 prefers-reduced-motion 降级（动效瞬时完成、骨架屏停闪）。
  5. 收藏 / 对比 / 深色模式状态会写入 localStorage，跨页面保持；「收藏与清单、我的、搜索、对比页」不在本轮 4 页范围，入口以 Toast 说明。
  6. 设计令牌、动效规范与待确认清单见同目录 设计说明.md。
