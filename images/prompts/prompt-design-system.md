## 1. 视觉定位（对齐已定稿设计基调）

**「杂志感大图 ＋ 柔和点缀」**（计划 §9 决策 #2）。落到摄影语言：

| 设计语言 | 摄影转译 |
| --- | --- |
| 杂志感大图 | 真实摄影质感、构图克制、画面有呼吸感留白、主体清晰突出；竖幅 3:4 对齐卡片流（mockups §3.2 封面 3:4 占位） |
| 柔和点缀 | 品牌色以「道具/服装/环境」柔和出现：奶油色（#FAF7F1 墙面/衣着）、陶土橘（#B4552F 贝雷帽/咖啡杯/花束）、灰绿（#6E7F5E 植物/布艺）；不出现高饱和撞色 |
| 色调 | 暖调低饱和，自然肤色，阴影偏暖不死黑，高光柔和不死白 |
| 质感 | 真实皮肤纹理与织物纹理，克制后期感；不用 HDR 味、不用浓重胶片颗粒 |

## 2. 全局风格基线（每条提示词共用）

### 2.1 风格尾缀（`global_style_suffix`，逐条拼在提示词末尾）

```
真实摄影质感，自然色彩，柔和暖调低饱和，画面干净有留白，杂志感构图，高清细腻细节
```

### 2.2 镜头基线

- 默认等效全画幅视角；焦段按条目机位取 24/35/50/85mm 四档（与计划 §2.2「机位与构图」一致）；
- 人像与半身默认大光圈浅景深（背景柔化、主体锐利）；旅行「人小景大」用广角小光圈（前后景同焦清晰）；
- 机位高度逐条指定：平视 / 低机位仰拍 / 垂直俯拍 / 侧面 45°，全部竖幅。

### 2.3 构图基线 v1.1（2026-10-28 用户确认后增补）

> 作用范围：尚未生成的 72 条（第二批起）；已完成的 28 张不重出、清单字段不动。与 §2.2 镜头基线冲突处，以本节为准。

1. **人物占比显著缩小**：以环境人像为主，人物高度约占画面 1/4–1/2（依姿势类型裁量），场景成为画面主体；逐条在提示词构图句中写明占比（约占画面高度四分之一/三分之一/二分之一）；
2. **场景更精致开阔**：优先开阔水岸、大草坪、极简建筑立面、有设计感的街角、通透室内大窗景等大空间场景；背景保持干净无杂乱元素，真实摄影感与杂志感基调不变；
3. **取景搭配**：全身（动态/大场景类）＋ 九分身（脚踝上方取景，避免切脚一半，适合站姿/倚靠/道具类）＋ 半身（室内近景类）按姿势类型搭配，逐条指定；
4. **三分法站位**：主体置于三分线或交点附近，视线方向与运动方向留出呼吸空间；地面/天空按条目留白；
5. **特写·局部类（CLOSE）**：保持特写逻辑不变，背景由纯色改为带环境层次（窗景光斑、色块虚化、前景柔纱等）；**多人类（DUO）**：两人/三人完整入镜不裁切，按三分法分布。

修订实施方式：逐条只替换/插入「构图句」（句首为竖构图/机位/视角关键词），人物特征、服装、动作、光线、画质尾缀与负向词均不动；修订后逐条校验 ≤300 字。

### 2.4 光线基线

- 主光自然光：柔和侧光 > 逆光发丝光 > 黄金时刻暖光；室内以窗光为主（对齐计划 §2.1 E/F 类「窗光是主角」）；
- 夜景条目（STREET-10/HOME-10）用「常亮暖光源补光＋环境霓虹/台灯」，人脸有光不死黑；
- 剪影条目（ST-10/BACK-08/CAFE-06）明确「人物收成纯黑剪影、天空/光源保留层次」。

### 2.5 画质词与禁用词

- **用**：真实摄影、高清细腻、自然光影、肤质真实、构图干净；
- **不用**：8K/超写实等夸张词（易触发塑料感）、卡通/插画/3D 渲染、景深合成感、重滤镜、HDR。

## 5. 负向词体系

生成通道（Seedream，方舟 `+gen`）**没有独立负向词参数**，采用双保险：

1. **内联避免句**（逐条拼入提示词，约占 20 字）：
   `画面避免：手部畸形、肢体扭曲、文字水印`
2. **完整负向清单**（JSON `global_negative`，供未来 SD/ComfyUI 通道与人工筛片对照）：

```
手指畸形、多余手指、缺手指、肢体扭曲、关节反折、比例失调、五官变形、斜视、
塑料感磨皮皮肤、过度美颜、油画感、卡通、插画、3D渲染、
画面中出现文字、水印、logo、边框、拼贴、
名人长相、明星脸、儿童、未成年人、
过度曝光死白、死黑细节丢失、HDR味、重噪点、构图歪斜、地平线切头、
水印字样、二维码、相机界面截图感
```

3. **人工筛片重点**（计划 §4.4）：手型、关节、左右方向、面部瑕疵——QA 结果记录在 manifest `qa` 字段。

## 6. 提示词结构模板（逐条 100 个）

```
[品类场景开场] ＋ [人物固定特征串] ＋ [服装] ＋ [姿势动作（改写自计划 §2.2「姿势要点」，逐条忠实）]
＋ [场景细节] ＋ [镜头与构图（改写自 §2.2「机位与构图」）] ＋ [光线] ＋ [风格尾缀] ＋ [避免句]
```

- 长度约束：模型目录建议中文 ≤300 字，全部条目控制在 ~300 字内；
- 忠实性：姿势与机位字段逐条对应计划 §2.2 原文，不添加清单外的动作语义（如「连拍」转为「动感抓拍瞬间」的视觉描述）。

## 7. 生成规格（2026-10-28 按实测更新）

| 项 | 取值 | 依据 |
| --- | --- | --- |
| 模型（默认） | `doubao-seedream-5-0-pro-260628`（现役旗舰，支持 seed 固定复现） | 实测：4.5 与 5.0-lite 服务端返回 **retiring 无法开通**（其免费额度随之作废）；5.0-pro `models get` 返回 ToICompletion **0.3 元/张**（账号无折扣） |
| 备选模型 | `doubao-seedream-5-0-flash-260915`，**0.12 元/张** | 快速档，成本约为 pro 的 40%；风格质量待试点对比 |
| 通道 | `arkcli api arkruntime.generate_images`（模型名直接调用） | 实测：本账号 platform 数据面**仅接受 ep-\***，`+gen` 传模型名被客户端拦截；账号当前无已部署 EP |
| 前置条件 | 在方舟控制台「模型开通页」调整/关闭**安全体验模式** | 实测：新开通模型默认被用量上限暂停（pro/flash 均如此），CLI 无调整入口 |
| 画幅 | 竖幅 3:4 → `1728x2304`（总像素 3.98M，在 5.0-pro 区间 [921600, 4624220] 内） | 适配卡片流与详情轮播；显示端 srcset 480/768/1080 三档再缩 |
| 水印 | `watermark: false`（服务端默认 true，显式关闭） | 杂志感样图不烧字；显式 AI 标识在应用层做「AI 示意图」角标（见合规文档） |
| 种子 | `seed = md5(姿势ID) mod 2^31`；5.0-pro/flash 支持 `[-1, 2147483647]` 固定复现 | 4.5/5.0-lite 不支持 seed，弃用后此约束解除 |
| 输出格式 | jpeg | 源图入库，应用侧再转 WebP 三档 |
| 命名 | `images/pilot/{POSE-ID}.jpg`（试点）；全量确认后落 `images/{POSE-ID}.jpg` | 按姿势编号命名 |

**成本估算（按 0.3 元/张）**：试点 10 张 ≈ 3 元；全量 100 张 ≈ 30 元（flash 约 12 元，质量对比后定）。


## 9. 待确认清单（不擅自拍板）

1. **模型选择**：默认 `doubao-seedream-5-0-pro`（0.3 元/张）。原定的 4.5（免费 200 张）与 5.0-lite（免费 41 张）经服务端实测均为 **retiring 型号，无法开通，免费额度作废**；4.0（免费 200 张）疑似同类状态，未再验证。是否用 flash（0.12 元/张）出 1–2 张对比图，待定。
