# 摆拍手册 PoseGuide · 示例图合规与 AI 生成内容标识方案

> 版本 v1.0 · 2026-10-28 · 对应《拍照姿势App项目计划.md》§4（取材合规要求）与《人工智能生成合成内容标识办法》（2025-09-01 施行）
> 配套：`prompts/prompt-design-system.md`（提示词约束）、`manifest.json`（生成台账）

## 1. 内容来源合规

| 风险点 | 本项目做法 |
| --- | --- |
| 真实人物肖像权 | 全部人物为 AI 生成的**虚构普通人**：提示词仅描述外貌特征（发型/气质/妆造），不使用任何真实姓名、公众人物指向或「某明星同款」表述；3 位虚构模特（M1/M2/M3）特征串固定，避免撞脸真实个体 |
| 未成年人 | 提示词全局限定「二十多岁」；负向词清单包含「儿童、未成年人」（计划 §4.3-5：V1 不用儿童模特） |
| 版权与地标 | TRAVEL 类一律用通用自然/城镇景观（海岸、灯塔、公路、山野、generic 小镇），不出现可识别品牌地标（主题乐园、宗教场所等）；不生成任何带真实 logo 的商品/门店 |
| 商标与文字 | 负向词含「画面中出现文字、水印、logo、二维码」；`watermark: false` 关闭服务端水印字样 |
| 品类敏感 | 姿势、服装、场景均为日常向；不生成敏感姿态或暗示性内容 |

## 2. 显式标识（用户可见）

按《标识办法》第四条，AI 生成内容需在**显要位置**作显式标识。方案：

1. **卡片流/详情页角标**：所有 AI 示意图右上角固定「AI 示意图」胶囊角标（设计令牌：底 `--c-ink` 半透明、白字 11px，圆角 full），列表页与详情轮播常显、不随滚动隐藏；
2. **详情页说明行**：图集下方固定一行弱化文字：「本图为 AI 生成的虚构人物示意，用于姿势教学参考」；
3. **分享/导出图**：分享卡片右下角带「AI 生成」角标随图导出（分享场景脱离 App 环境，标识必须随图走）；
4. 原型落地建议：mockups 的 `poseSVG()` 占位替换为真实图后，在 `assets/base.css` 增加 `.ai-badge` 组件统一实现。

## 3. 隐式标识（元数据）

按《标识办法》第五条，生成服务提供的隐式标识（元数据）应保留。本项目分层记录：

1. **生成台账**（`manifest.json`，唯一事实源）：姿势ID、图片路径、提示词（指向清单 `prompt_id`）、模型名＋版本、种子、日期、尺寸、水印开关、SHA-256、状态与 QA 结论——可完整复现每张图的生成过程；
2. **源图元数据**：方舟生成的 jpeg 本身是否内嵌 AIGC 元数据（C2PA 等）**未验证**（本批 0 张产出）；若服务端未内嵌，在图片进入应用构建管线前统一注入：XMP `photoshop:Credit = "AI-generated (Seedream)"` + EXIF `ImageDescription = "AI-generated content / AI 生成内容"`（用 exiftool/PIL 批处理，列为上线前待办）；
3. **URL 台账**：方舟预签名 URL 24h 失效，不作为长期凭证；持久凭证以本地文件 SHA-256 为准。

## 4. 生成通道与账号合规

- 通道：火山方舟（Volcano Ark）`arkcli`，模型 `doubao-seedream-5-0-pro`（现役）/ `5.0-flash`（备选），按量计费；
- 生成请求与响应均经账号 API Key 完成，密钥不落仓、不进台账（台账只记 Key 后四位掩码可选项）；
- 内容审核：方舟服务端内置内容安全审核（命中即拒绝生成）；提示词本身已按 §1 约束，双保险。
